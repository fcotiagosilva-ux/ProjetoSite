# Fluentia

Aplicativo mobile de prática de inglês para Android e iOS, criado com Expo e React Native.

## Rodar o app

1. Instale o [Node.js 18.17+](https://nodejs.org/).
2. Instale o Expo Go no celular ou use um emulador Android/iOS.
3. Execute:

```powershell
cd mobile-app
npm install
npm start
```

Escaneie o QR Code exibido pelo Expo Go. Para abrir diretamente em um emulador:

```powershell
npm run android
npm run ios
```

## O que já existe no app

- Tela inicial com sequência diária e recomendações.
- Prática interativa de conversação.
- Feedback imediato sobre respostas em inglês.
- Tela de progresso com métricas e conquistas.
- Tela de perfil e preferências.
- Navegação inferior otimizada para uso no celular.

O app não depende de WhatsApp. A prática funciona localmente nesta primeira versão; uma API própria de IA pode ser conectada depois, usando um backend seguro e sem chaves no aplicativo.
